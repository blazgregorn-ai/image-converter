# Image Converter

A fast, 100% client-side, privacy-first web utility that converts multiple images instantly right in your browser. No server uploads, zero ads, and completely free.

## ✨ Features
- **Client-Side Processing:** Your files never leave your device, ensuring total privacy.
- **Batch Conversion:** Convert multiple images simultaneously.
- **Lightweight & Fast:** Built with clean web standards with zero bloat.
